# MathBot — GitHub Pages

## Archivos
- `index.html`: aplicación web con 10 ejemplos clicables, operaciones matemáticas y práctica.
- `fondo_matematicas.png`: fondo matemático.

## Publicación
1. Crea un repositorio en GitHub.
2. Sube `index.html` y `fondo_matematicas.png` a la raíz.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y carpeta `/(root)`, y pulsa **Save**.
6. Copia la URL que aparezca en la sección Pages una vez publicado.

La página utiliza Nerdamer, Math.js y Plotly desde CDN, así que necesita conexión a Internet. Las operaciones simbólicas tienen límites; comprueba los resultados antes de entregar. Completa los nombres de los integrantes.
